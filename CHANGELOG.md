# Changelog

## 0.1.0 - 2026-11-23

- Add the `rex` windowing module: Rex tabs, splits, sidebar, and floating
  popups from Kakoune, with windowing detection support.
- Add `rex-pick` and the Rex-side `lua/kak.lua` module with palette pickers
  for files, git, grep, buffers, symbols, and more, falling back to `kks-*`
  fzf scripts.
- Add opt-in compatibility aliases with `rex-enable-default-aliases`.
